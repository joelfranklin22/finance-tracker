# Finance Platform - React + Node (Express) + MySQL

- client/   React (Vite) UI, Clerk login
- server/   Node + Express API, plain SQL (mysql2), Gemini receipt scan
- database/ schema.sql (run it once in MySQL Workbench)

1. Run database/schema.sql in MySQL Workbench
2. Put your MySQL password in server/.env (DB_PASSWORD)
3. npm run setup
4. npm run dev  ->  http://localhost:5173
